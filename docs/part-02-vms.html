02 Azure model

The VM is not
the connection.

A VM connects to the network through a Network Interface Card. The NIC owns the private IP and subnet relationship; the optional public IP is a separate Azure resource.

03 Deployment

Create the
web VM.

Use SSH public-key authentication. Give the lab VMs public IPs temporarily so you can connect from your Mac; production access will move to Bastion later.

Resource grouprg-cloudnet-prod
VM namevm-web-01
ImageUbuntu Server 24.04 LTS
Architecturex64
VNetvnet-cloudnet-prod
Subnetsnet-frontend
Public IPpip-vm-web-01
Inbound portSSH (22) only
AuthenticationChoose SSH public key instead of password authentication. Never select All ports.
Azure CLI / vm-web-01
az vm create \
  --resource-group rg-cloudnet-prod \
  --name vm-web-01 \
  --image Ubuntu2404 \
  --vnet-name vnet-cloudnet-prod \
  --subnet snet-frontend \
  --admin-username azureuser \
  --ssh-key-values ~/.ssh/id_rsa.pub \
  --public-ip-address pip-vm-web-01 \
  --nsg-rule SSH
Use the public key path that exists on your machine. The exact Ubuntu image alias can change; verify with az vm image list if needed.

06 Linux inspection

from inside.

SSH into each VM and inspect the interface, route table, DNS settings, hostname, and listening ports. These commands are the beginning of your Linux networking toolkit.

hostnameConfirm which VM you are on.
ip addrFind the private address on eth0.

resolvectl statusInspect DNS configuration.
ss -tulpnSee listening TCP/UDP ports.
Expected route shape10.10.1.0/24 dev eth0default via 10.10.1.1 dev eth0

Local subnet traffic uses eth0; everything else uses the default gateway.

07 Platform details

Azure gives the
NIC its context.

You did not normally type the VM's private IP into Ubuntu. Azure provides network configuration through its platform networking and DHCP behavior.

Azure platformNICUbuntu / eth0private IP · route · DNS context
Azure subnet reservation

10.10.1.0/24

10.10.1.0 network10.10.1.1 gateway10.10.1.2 platform10.10.1.3 platform10.10.1.255 reserved
256 total − 5 reserved = 251 usable
!

Remember: Azure reserves the first four and last IP address of every subnet. A /24 has 256 mathematical addresses, but 251 usable Azure addresses.
