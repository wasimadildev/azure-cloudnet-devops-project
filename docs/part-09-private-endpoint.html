01 The problem

Azure service,
private path.

Without Private Link, a backend VM reaches a Storage public endpoint. With a private endpoint, the service gets a private IP representation inside your VNet.

WITHOUT PRIVATE ENDPOINT
vm-api-01 Internet / public endpoint Storage

Azure resources still use the public service endpoint.

WITH PRIVATE ENDPOINT
vm-api-01 10.10.3.x Private Link Storage

Traffic stays on private Azure networking.

↗

Private Endpoint and Private Link are related, not identical. The endpoint is a network interface/private IP in your VNet; Private Link is the underlying private service connectivity technology.

04 Private endpoint

Create the
private connection.

Create the endpoint from the Storage Account networking settings. Select the Blob subresource and integrate the correct private DNS zone.

  1. 01

    Open Storage networking

    Open the Storage Account, choose Networking → Private endpoint connections → + Private endpoint.

  2. 02

    Choose the resource

    Connect to an Azure resource in your directory. Select the Storage Account and target subresource blob.

  3. 03

    Choose the VNet and subnet

    Select vnet-cloudnet-prod and snet-database. Use dynamic private IP allocation for this lab.

  4. 04

    Enable DNS integration

    Choose Yes for private DNS integration. The Blob zone is privatelink.blob.core.windows.net.

  5. 05

    Validate before restricting

    Create the endpoint, find its private IP, test DNS and TCP 443, then disable public access only after the private path works.

Azure CLI / inventory
az network private-endpoint list \
  --resource-group rg-cloudnet-prod \
  --output table

az network private-endpoint show \
  --resource-group rg-cloudnet-prod \
  --name pe-storage-cloudnet \
  --output json

az network private-endpoint show \
  --resource-group rg-cloudnet-prod \
  --name pe-storage-cloudnet \
  --query "networkInterfaces[].id" \
  --output tsv
The Portal is the primary creation path; use the returned NIC ID to inspect the endpoint private IP.
05 DNS matters

Private IPs need
private resolution.

Your application keeps using the normal Storage hostname. Private DNS changes where that hostname resolves, so you do not hard-code the endpoint IP.

Applicationstorage.blob.core.windows.net
Private DNS zoneprivatelink.blob.core.windows.net
Private A record10.10.3.x
Private Endpointpe-storage-cloudnet
Required DNS stateVNet link + A record + private endpoint IP

If DNS resolves to a public address, the endpoint can exist while the application still bypasses the intended private path.

!

Connectivity is not authorization. A 403 means Storage received and understood the request but rejected the credentials or permissions. DNS failure and timeout are different problems.

07 Private-only access

Validate first.
Restrict second.

A private endpoint does not automatically disable the Storage public endpoint. Once private DNS and connectivity work, configure the Storage Account network settings for private-only access if that is the intended design.

01Private endpoint createdservice still testable
02DNS and TCP validatedprivate path proven
03Public access restrictedprivate path becomes required
Do not skip the order

Disabling public access before private DNS and endpoint testing can create a confusing failure with no working fallback.

08 Compare concepts

Private paths
are not interchangeable.

Each networking capability solves a different problem.

PeeringNETWORK ↔ NETWORKConnects VNet A to VNet B.
Private EndpointNETWORK → SERVICEMaps a supported PaaS service into the VNet.
NAT GatewayPRIVATE VM → INTERNETProvides controlled outbound egress.
Service EndpointVNET → PUBLIC SERVICE MODELPrivate Azure backbone path without a VNet IP representation.

10 Diagnosis

Debug in layers,
not guesses.

Private PaaS failures usually become clear when you walk from name resolution to authorization.

02Private IP10.10.3.x

Common failure

Private endpoint exists, but DNS resolves the Storage hostname to a public endpoint. Check the zone, A record, VNet link, and VM DNS configuration.
